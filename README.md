# Data Science Learning Journey 🚀

## 📚 Overview

This repository showcases my data science learning journey, from foundational concepts to more advanced topics. It contains notebooks, projects, and scripts I've developed since starting this path in 2019.

My goal is to share my knowledge and provide resources for anyone learning or reviewing core data science concepts.
The material is inspired by courses **[Data Scientist in Python Certificate Program](https://www.dataquest.io/path/data-scientist/)** from **Dataquest** and **[IBM Data Science Professional Certificate](https://www.coursera.org/professional-certificates/ibm-data-science)** from **Coursera**.

I’ve explored Python, Data Analysis and Visualization, Data Cleaning, SQL, Object-Oriented Programming (OOP), and Machine Learning fundamentals using real-world datasets.

I plan to continuously update this repository with new topics and projects as I keep learning and practicing. My goal is to maintain this repository as both a showcase of what I've learned in data science and as a personal reference to review topics.
